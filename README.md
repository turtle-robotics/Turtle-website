# TURTLE Robotics Website

Website for TURTLE Robotics at Texas A&M University.

## Tech Stack

- React 18
- Vite 6
- React Router 6
- Tailwind CSS 3
- Inter font from Google Fonts
- npm

## Getting Started

### Prerequisites

- Node.js 22.x
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/turtle-robotics/Turtle-website.git

# Change to the project directory
cd Turtle-website

# Install dependencies
npm install

# Start a development server
npm run dev

# Create a production build
npm run build

# Preview the production build
npm run preview

# Format files in src/ with Prettier
npm run format
```

## Project Structure

```text
src/
├── components/       Shared React components
├── data/
│   └── projects.js   Project data
├── pages/            Route components
├── App.jsx           Route definitions
├── main.jsx          React entry point
└── main.css          Global CSS and CSS variables
```
